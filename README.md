# my-robot-langium# my-robot-langium

## Description

`my-robot-langium` est un projet qui vise à créer un langage de programmation spécifique pour contrôler des robots. Ce langage est conçu pour être facile à utiliser et à comprendre, tout en offrant des fonctionnalités avancées pour la programmation robotique.

### Prérequis 

- Node.js (version 14 ou supérieure)
- npm (Node Package Manager)
